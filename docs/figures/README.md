# Paper figures

All 7 figures are generated by a single script: [`scripts/make_figures.py`](../../scripts/make_figures.py).

## Why a single script?

- **Reproducible**: re-run any time eval results change, no manual re-drawing
- **Consistent style**: IEEE-quality fonts, sizes, and colors set once at the top
- **Version-controlled**: figures live as `.py` source, outputs are regenerable

## Generate

```bash
python scripts/make_figures.py
```

Outputs (PDF + PNG) land in `docs/figures/`:

| File | Source | What it is |
|---|---|---|
| `fig1_architecture.pdf` | graphviz | Full system: client → API → multimodal preprocessors (STT, image processor + CBAM) → agent → inference services (LLM, retrieval, KG, BanglaT5) → data. TTS shown as a parallel output endpoint. GPU vs. CPU nodes color-coded. |
| `fig2_workflow.pdf` | graphviz | LangGraph state machine with bounded retry loop (matches `agribot/agent/graph.py`) |
| `fig3_retrieval.pdf` | matplotlib + `evaluation/results/retrieval_latest.json` | Recall@k bars + MRR/N/avg-latency badge |
| `fig4_latency.pdf` | matplotlib + `evaluation/results/latency_latest.json` | Per-stage cumulative latency (horizontal stacked bar). Includes future agent nodes automatically. |
| `fig5_confusion.pdf` | matplotlib + `docs/cnn_confusion.json` | CBAM CNN confusion matrix, row-normalized (per-class recall %) |
| `fig6_kg_example.pdf` | graphviz | KG dialect-expansion example. Aliases match real entries in `agribot/knowledge_graph/seed_data.py`. Symptom/treatment neighbors are illustrative — adjust to match what your seeder actually stores. |
| `fig7_screenshots.png` | PIL + `docs/figures/ui_*.png` | Frontend triptych (text / voice / image). Portable font cascade (Times → DejaVu → PIL default). |

## Data files the script expects

| Figure | Expected input | Generated by |
|---|---|---|
| 3 | `evaluation/results/retrieval_latest.json` | `python evaluation/eval_retrieval.py` |
| 4 | `evaluation/results/latency_latest.json` | `python evaluation/eval_latency.py` |
| 5 | `docs/cnn_confusion.json` (6×6 array of ints) | Export from the training notebook's eval cell |
| 7 | `docs/figures/ui_text.png`, `ui_voice.png`, `ui_image.png` | Manual screenshots from the running app |

Missing inputs produce a clear warning and either skip the figure (7) or use a labeled placeholder so the layout slot is preserved during drafting (3, 4, 5).

## Regenerating one figure at a time

Edit the bottom of `scripts/make_figures.py` — comment out the figures you don't want to re-render:

```python
if __name__ == "__main__":
    # fig1_architecture()
    # fig2_workflow()
    fig3_retrieval()        # only regenerate this one
    # fig4_latency()
    ...
```

## IEEE quality checklist

The script enforces these automatically:
- Vector PDF + 300-DPI PNG side-by-side
- Times-family serif fonts at 9 pt
- Single-column width = 3.5 in; wide = 7.16 in
- Color-blind safe palette (blue/orange/gray)
- TrueType font embedding (`pdf.fonttype = 42`) so reviewers can copy text out of figures
